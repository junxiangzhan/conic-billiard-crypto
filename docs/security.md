# 安全性邊界與威脅模型

這是**動力系統 + 密碼學教學研究原型**，不是正式 DH 協議，也沒有做常數時間或實際協議安全工程。

## 需要保護的是什麼？

公開：有限域 \(\mathbb F_p\)、圓錐曲線 \(C\)、反射規則、初始狀態，以及在建立群後的生成元 \(G\)。秘密：整數 \(n\)（以群階取模）。

若一個完整、非退化的不變層與橢圓曲線群有有效對應 \(\Phi\)，且一次撞擊對應群平移 \(G\)，則

\[
\Phi(T^n(X_0))=\Phi(X_0)+[n]G.
\]

恢復 \(n\bmod\operatorname{ord}(G)\) 的問題於是可能成為該群上的 DLP。此判斷必須針對**實際挑選的有限域不變層**證明；不能由曲線形狀直接宣告成立。

## 不能使用「連續撞擊」直接做 DH

\[
T^a(T^b(X_0))=T^{a+b}(X_0),
\]

這是秘密指數的相加，而標準 DH 需要乘積：

\[
[a]([b]G)=[ab]G.
\]

若直接公開 \(U_A=U_0+[a]G\)、\(U_B=U_0+[b]G\) 然後取 \(U_0+[a+b]G\)，旁觀者可計算 \(U_A+U_B-U_0\)，完全不需解 DLP。

`python -m conic_billiard.toy_dh` 展示在**已建立 Jacobi 群模型的橢圓型撞擊**上使用真正的群純量乘法，並且用 BSGS **立即恢復示範私鑰**。示範子群階 67，故沒有實際安全性。

## 有限域與群階不等於安全強度

- \(p\) 有 256 bits **不代表**所選撞擊循環有 256-bit 的大質數階。
- 週期 60 只有小質數因子；週期 58 含 29，雖然短於 60，作為候選子群更值得先注意。
- 若固定小矩陣足以完全忠實表示撞擊鏈，矩陣 DLP 可能降到低次擴張有限域 DLP，而不是典型 ECDLP。
- 只公開位置可能遺失方向/提升符號；需要先定義完整的公開狀態與驗證方式。
